# Проверка LightLauncher 1.3.3

Дата: 2026-10-28. Xiaomi MiTV-MSSP1, Android TV 9 / API 28.

- Собраны debug, подписанный release и инструментальный тест. Android Lint завершился без ошибок; предупреждения о прежних версиях инструментов, banner, ориентации и backup не подавлялись.
- Обновление установлено поверх 1.3.2 с прежней подписью.
- Все 24 инструментальные проверки навигации и избранного прошли на ТВ.
- На снимках экрана проверены обычное состояние и фокус иконок настроек, входов и действий. Иконки центрированы, на белой подсветке становятся тёмными.
- В UI-дереве у всех трёх кнопок пустой текст, сохранены `contentDescription`, `clickable` и `focusable`.
- Кнопка действий открывает меню выбранного приложения; иконка входов открывает список HDMI/AV. Один захват UI-дерева диалога завершился ошибкой UiAutomator, после чего открытый диалог подтверждён снимком экрана.
- Иконка настроек открывает системные настройки; Home возвращает в LightLauncher.
- Иконки — локальные VectorDrawable; сторонние runtime-библиотеки, сетевые разрешения и постоянные анимации не добавлялись.

Изменение касается трёх кнопок. Перезагрузка ТВ, физическое переключение HDMI и чтение озвучивания экранным диктором в этом прогоне не проверялись. Визуальная проверка и доступные названия кнопок не означают полного аудита доступности.

Предыдущие аппаратные замеры: [1.3.2](VALIDATION.md). Для 1.3.3 ускорение или изменение FPS по этим проверкам не заявляется.
