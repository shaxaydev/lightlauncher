# Проверка LightLauncher 1.3.2

Дата: 2026-10-23.

## Выполнено

- Подписанная release-сборка, debug-сборка и APK инструментального теста собираются.
- Android Lint: 0 ошибок, 6 предупреждений о версиях инструментов, banner vector, фиксированной ориентации и настройке backup. Предупреждения не подавлялись ради результата.
- 24 инструментальные проверки прошли на Android 15 / API 35, `sdk_gphone64_arm64`, временный эмулятор с плотностью 320 dpi.
- Проверены D-pad, фокус и фон, меню долгого OK, перестановка, сохранение после пересоздания Activity, удаление, пустое избранное, дубликаты и повреждённый JSON.
- Точная копия подготовленных для Git файлов собирает debug и проходит Lint без `.signing/` и `local.properties`.
- Подпись APK проверена; сертификат совпадает с LightLauncher 1.3.1.
- Подготовленные файлы проверены на ключи подписи, приватные IP, абсолютные локальные пути и характерные форматы токенов. Проверка не является гарантией обнаружения произвольного секрета.

## Ограничения проверки

Новая сборка 1.3.2 не проверялась на физическом Xiaomi: ADB-подключение к ТВ было недоступно. Android 9 на MiTV-MSSP1 проверялся для предыдущей версии до рефакторинга. Эмулятор не подтверждает HDMI, холодную загрузку, поведение HOME конкретной прошивки и производительность реального ТВ.

Это рефакторинг и подготовка публичного проекта; заявление об ускорении приложения по этим проверкам не делается.

Команды воспроизведения — в [README](../README.md#проверки).
