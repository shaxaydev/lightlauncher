# Проверка LightLauncher 1.3.2

Первая проверка: 2026-10-23. Аппаратная проверка дополнена 2026-10-28.

## Выполнено

- Подписанная release-сборка, debug-сборка и APK инструментального теста собираются.
- Android Lint: 0 ошибок, 6 предупреждений о версиях инструментов, banner vector, фиксированной ориентации и настройке backup. Предупреждения не подавлялись ради результата.
- 24 инструментальные проверки прошли на Android 15 / API 35, `sdk_gphone64_arm64`, временный эмулятор с плотностью 320 dpi.
- Проверены D-pad, фокус и фон, меню долгого OK, перестановка, сохранение после пересоздания Activity, удаление, пустое избранное, дубликаты и повреждённый JSON.
- Точная копия подготовленных для Git файлов собирает debug и проходит Lint без `.signing/` и `local.properties`.
- Подпись APK проверена; сертификат совпадает с LightLauncher 1.3.1.
- Подготовленные файлы проверены на ключи подписи, приватные IP, абсолютные локальные пути и характерные форматы токенов. Проверка не является гарантией обнаружения произвольного секрета.

## Xiaomi MiTV-MSSP1: 2026-10-28

- Установлен опубликованный APK 1.3.2 поверх 1.3.0 на Android TV 9 / API 28. Подписи совпадают; удаление приложения и сброс данных не выполнялись.
- Все 24 инструментальные проверки прошли на самом телевизоре.
- Список видимого избранного и его порядок совпали до обновления и после автотеста.
- Через пультовые события проверены запуск YouTube кнопкой «Открыть», системные настройки и возврат по Home.
- Меню входов открылось и перечислило HDMI 1, HDMI 2 (ARC), HDMI 3 и AV. Физический сигнал не переключался.
- Подтверждены версия 1.3.2, назначение HOME и активный экран лаунчера после проверок. В журнале текущего процесса нет FATAL EXCEPTION или OutOfMemoryError.

### Короткий замер на одном ТВ

Один сценарий до и после обновления: 14 перемещений фокуса по тому же избранному после трёх попыток запуска процесса. Результаты относятся только к этому короткому прогону.

| Показатель | 1.3.0 | 1.3.2 |
|---|---:|---:|
| Кадр, 50-й перцентиль `gfxinfo` | 6 мс | 6 мс |
| Кадр, 95-й перцентиль | 10 мс | 9 мс |
| Медленные кадры | 1 / 235 | 0 / 234 |
| PSS после прогона | 26 382 КиБ | 24 772 КиБ |

Сравнение времени холодного запуска не приводится: одна из попыток на 1.3.0 вернула в `am start -W` другую Activity, поэтому считать её холодным запуском лаунчера нельзя. Указанные кадровые метрики собраны в конце сценария на самом лаунчере. Повторные длительные прогоны для статистической оценки не выполнялись.

## Ограничения проверки

Холодное включение, перезагрузка ТВ, физические кнопки пульта и фактическое переключение HDMI-сигнала в этой проверке не испытывались. Нажатия генерировались через ADB и инструментальный тест на реальном телевизоре. Поддержка других прошивок и устройств по этим результатам не заявляется.

Это рефакторинг и подготовка публичного проекта; заявление об ускорении приложения по этим проверкам не делается.

Команды воспроизведения — в [README](../README.md#проверки).
